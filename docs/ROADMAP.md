# Milestones

Each milestone runs, is tested at eye height and on a phone, and is committed before the next.

| # | Milestone | Done when |
|---|---|---|
| 0 | **Setup and deploy** | Vite + three.js scene, Worker with `/api/health`, auto-deploy from GitHub to Cloudflare. |
| 1 | **Landscape** | Copernicus DEM terrain around the site, river (marked "inferred"), sky, fog, fly-over camera (desktop + touch). |
| 2 | **The city** | Traced excavated walls (HR, DK, VS, SD areas) as JSON; procedural houses filling the rest; citadel mound with the Great Bath; brick shader; performance budget for phones. |
| 3 | **Certainty layer + info panel** | One control: "alive" / "evidence". Click any feature: what it was, what we know, how sure, sources. |
| 4 | **Walk mode** | First person at eye height, WASD + touch, collision, minimap. |
| 5 | **Time of day** | Sun from dawn to night, stars, warm night lamps (imagined). |
| 6 | **Monsoon** | Rain and water flowing through the covered drains toward the river. |
| 7 | **Life in the city** | Simple figures doing crafts, clickable craft notes. |
| 8 | **City through time** | Slider: founding → height → decline → burial → excavation → today; then-and-now split. |
| 9 | **Indus script** | Signs and seals explorer, sign frequencies, theories without claiming a decipherment. |
| 10 | **Sound** | Generative ambience and music, one on/off control. |
| 11 | **Talk to a resident** | Gemini chat through the Worker, grounded only in curated notes, honest "nobody knows". |
| 12 | **Guide** | Ten-step tour, list of buildings, search. |
| 13 | **Polish** | Hover labels, link-preview image and meta tags, phone tuning, credits screen. |
